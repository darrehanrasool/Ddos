2. ARCHITECTURE OVERVIEW: HOW EVERYTHING CONNECTS
--------------------------------------------------------------------------------

The platform solves the real-world problem of detecting and mitigating DDoS attacks
across diverse network topologies (Cloud, Enterprise, Software-Defined Networks, and IoT).

Different networks expose completely different packet schemas and attack patterns:
  - Enterprise/Cloud: Heavy volumetric reflection (TFTP, DNS, NTP, LDAP, UDP-Lag)
  - Application-Layer: Slowloris, LOIC, HTTP Hulk attacks
  - SDN Networks: OpenFlow switch flow-table saturation attacks
  - IoT Networks: Low-power smart home and industrial botnet floods (Mirai, Gafgyt)

To address this without losing cross-domain accuracy:
  [Step 1] Ingest 6 specialized datasets (CIC-DDoS2019, CIC-IDS2017, NSL-KDD,
           SDN-DDoS, BoT-IoT, TON_IoT).
  [Step 2] Train dual-tier specialized models for EACH dataset:
           - Tier 1: HistGradientBoosting (Fast sub-millisecond pre-screening)
           - Tier 2: DeepResidualMLP (Deep high-dimensional feature extractor)
  [Step 3] Connect all specialized models into a single UnifiedDDoSPipeline:
           Ingress Traffic -> Schema Auto-Detection -> Fast Tree Screening ->
           Deep Residual Representation -> Meta-Ensemble Consensus ->
           Automated Mitigation (PASS, RATE LIMIT, QUARANTINE, BLOCK IP).


3. FREQUENTLY ASKED QUESTIONS
--------------------------------------------------------------------------------

Q1: Were the models downloaded from previous work?
A1: NO. No pre-trained models were downloaded from the internet.
    Only the raw dataset CSVs were downloaded. The models inside
    `models/dataset_specialized/` were trained directly on your machine
    (using Apple Silicon MPS acceleration) by `DatasetTrainer`.

Q2: Why do data/splits/ (train, test, validation) already contain files?
A2: Those 3 files (train_flows.csv, val_flows.csv, test_flows.csv) have timestamps
    from Oct 18, 17:13. They were created during earlier starter work on this repository
    by running `prepare_data.py` on a single sample of CIC-DDoS2019. That older work
    never trained any models (models/classical_ml/ was empty).
    The new multi-dataset architecture uses each dataset's own train/test split.

Q3: What do I actually have to train?
A3: All 6 dataset models are ALREADY trained and operational! You can run the
    pipeline right now using:
      .venv/bin/python src/ddos_ai/main.py pipeline --input demo
    If you want to retrain from scratch (e.g. with more epochs or different parameters),
    simply run:
      .venv/bin/python src/ddos_ai/main.py train-datasets --dataset all --epochs 10

Q4: How do I launch the Real-Time Cyber SOC Dashboard with beeping audio alerts?
A4: Run this single command in your terminal:
      .venv/bin/python src/ddos_ai/main.py dashboard --open-browser
    or:
      .venv/bin/python scripts/run_dashboard.py --open-browser
    This opens the interactive SOC dashboard at http://127.0.0.1:8080 featuring:
    - Real-time Safe (Green) vs Danger (Red) security status banner
    - Distinct acoustic beeps for Safe chime, Warning beep, Attack alarm, and Block siren
    - Interactive 1-click attack simulation buttons (SYN flood, IoT Mirai, SCADA, SDN)
    - Live scrolling timeline, packet telemetry feed, and Apple Silicon MPS telemetry.
