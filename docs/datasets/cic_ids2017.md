## 2. Capture Setup & Traffic Profile
- **Testbed Design**: Emulated production enterprise network with two interconnected domains:
  - **Victim Network**: Secure internal enterprise LAN featuring Web Server, Mail Server, Firewall, Domain Controller, and Windows/Linux workstations.
  - **Attacker Network**: External internet subnet staging multi-vector attacks against the victim infrastructure.
- **DDoS Target Day (Friday, July 7, 2017)**:
  - **Morning**: Botnet ARES execution.
  - **Afternoon (15:00 - 17:00)**: Large-scale volumetric DDoS attack utilizing LOIC (Low Orbit Ion Cannon) over HTTP/UDP, along with Slowloris, DoS GoldenEye, and DoS Hulk.
- **Record Count**: 225,745 bidirectional flows in the dedicated Friday afternoon capture.

---

## 3. Threat Taxonomy in CIC-IDS2017

| Attack Class | Mechanism | Transport Protocol | Primary Target Impact |
|---|---|---|---|
| **BENIGN** | Normal background employee web browsing, file transfer, and mail | TCP / UDP | Baseline normal operation |
| **DDoS (LOIC-HTTP)** | Coordinated HTTP request flood generated by volunteer or compromised botnets | TCP Port 80 | Exhausts Apache/Nginx worker connection pools |
| **DoS Hulk** | HTTP GET flood with randomized URL query parameters to bypass server caching | TCP Port 80 | Exhausts CPU via dynamic web page generation |
| **DoS GoldenEye** | HTTP Keep-Alive and No-Cache header abuse | TCP Port 80 | Holds server sockets open indefinitely |
| **DoS Slowloris** | Partial HTTP headers sent at periodic minimal intervals | TCP Port 80 | Starves concurrent socket limits with negligible attacker bandwidth |
| **DoS Slowhttptest** | Incomplete HTTP POST request body headers | TCP Port 80 | Exhausts web application request buffers |

## 4. Key Feature Columns
Extracted via CICFlowMeter, the key discriminating flow metrics include:
- `Destination Port`: Standard vs non-standard port distribution.
- `Flow Duration`: Extremely short in volumetric floods, extremely long in Slowloris.
- `Total Fwd Packets` & `Total Backward Packets`: Severe asymmetry in DDoS.
- `Flow Bytes/s` & `Flow Packets/s`: High-volume transmission spikes.
- `Fwd Packet Length Mean` & `Bwd Packet Length Mean`: Payload signature analysis.
- `SYN Flag Count`, `ACK Flag Count`, `RST Flag Count`: Protocol state transitions.
