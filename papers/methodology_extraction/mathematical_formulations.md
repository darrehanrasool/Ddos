# Mathematical Formulations in Network Flow Modeling & DDoS Detection

## 1. Flow Feature Extraction & Statistical Dynamics
Network flow records generated by tools like CICFlowMeter, Argus, or Zeek represent bidirectional flows summarized over 5-tuple tuples:
$$\text{Flow Key} = (\text{Src IP}, \text{Dst IP}, \text{Src Port}, \text{Dst Port}, \text{Protocol})$$

### 1.1 Packet Inter-Arrival Times (IAT)
For a sequence of packet arrival timestamps $\{t_1, t_2, \dots, t_K\}$ within a flow:
$$\Delta t_k = t_k - t_{k-1}, \quad \forall k \in \{2, \dots, K\}$$
The empirical mean, variance, and standard deviation are:
$$\mu_{\text{IAT}} = \frac{1}{K-1} \sum_{k=2}^{K} \Delta t_k$$
$$\sigma_{\text{IAT}}^2 = \frac{1}{K-2} \sum_{k=2}^{K} (\Delta t_k - \mu_{\text{IAT}})^2$$
Volumetric DDoS attacks (e.g. UDP or SYN floods generated by botnet stressers) exhibit near-zero variance $\sigma_{\text{IAT}}^2 \to 0$ due to automated packet generation loops.

### 1.2 Byte and Packet Rates
$$\text{Flow Packets/s} = \frac{K}{\Delta T_{\text{flow}}}, \quad \text{Flow Bytes/s} = \frac{\sum_{k=1}^K L_k}{\Delta T_{\text{flow}}}$$
Where $L_k$ is the payload length of packet $k$, and $\Delta T_{\text{flow}} = t_K - t_1$.

## 2. Information Theoretic Entropy Metrics
To detect distributed attacks launched from thousands of spoofed or zombie IPs, sliding window distributions are evaluated.

### 2.1 Normalized Shannon Entropy
For feature $X$ with $M$ unique outcomes in observation window $W$:
$$H(X) = -\sum_{i=1}^M \left(\frac{c_i}{N}\right) \log_2 \left(\frac{c_i}{N}\right)$$
The Normalized Entropy:
$$H_{\text{norm}}(X) = \frac{H(X)}{\log_2 M} \in [0, 1]$$
- **High Entropy ($H_{\text{norm}} \approx 1$)**: High diversity (e.g., normal web browsing to thousands of destination IPs and ports).
- **Low Entropy ($H_{\text{norm}} \to 0$)**: Anomaly/DDoS targeting a concentrated service endpoint.

### 2.2 Tsallis Non-Extensive Entropy
Generalizes Boltzmann-Gibbs statistics for heavy-tailed internet traffic:
$$S_q(X) = \frac{1}{q - 1} \left( 1 - \sum_{i=1}^M P(x_i)^q \right)$$
Where $q$ is the non-extensivity parameter ($q \to 1$ recovers standard Shannon entropy).

## 3. Machine Learning Algorithms & Optimization

### 3.1 Random Forest Gini Impurity and Split Optimization
For node $m$ with dataset $D_m$ containing classes $k \in \{1, \dots, K\}$:
$$p_{mk} = \frac{1}{|D_m|} \sum_{(\mathbf{x}, y) \in D_m} \mathbb{I}(y = k)$$
Gini Impurity:
$$G(D_m) = 1 - \sum_{k=1}^K p_{mk}^2$$
The optimal feature split $j^*$ and threshold $s^*$ maximize impurity reduction:
$$\Delta G(D_m, j, s) = G(D_m) - \left( \frac{|D_m^L|}{|D_m|} G(D_m^L) + \frac{|D_m^R|}{|D_m|} G(D_m^R) \right)$$

### 3.2 Logistic Regression & Cross-Entropy Loss
The probability that flow $\mathbf{x}$ is an attack ($y=1$):
$$P(y=1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$
Binary Cross-Entropy Loss with $L_2$ regularization:
$$\mathcal{J}(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right] + \frac{\lambda}{2} \|\mathbf{w}\|_2^2$$

## 4. Deep Neural Network Formulations

### 4.1 Hybrid 1D-CNN + BiLSTM Spatio-Temporal Model
Given packet flow feature sequence $\mathbf{X} \in \mathbb{R}^{L \times d}$:
1. **Spatial Convolution**:
   $$\mathbf{z}_j^{(1)} = \text{ReLU}\left( \mathbf{W}_{\text{conv}} * \mathbf{X}_{j:j+k-1} + \mathbf{b} \right)$$
2. **MaxPooling**:
   $$\mathbf{p}_j = \max_{r \in [1, s]} \mathbf{z}_{j \cdot s + r}$$
3. **Temporal Processing via BiLSTM**:
   $$\mathbf{h}_t = [\overrightarrow{\text{LSTM}}(\mathbf{p}_t) \,\|\, \overleftarrow{\text{LSTM}}(\mathbf{p}_t)]$$
4. **Classification Head**:
   $$\hat{\mathbf{y}} = \text{softmax}(\mathbf{W}_c \mathbf{h}_T + \mathbf{b}_c)$$

### 4.2 Autoencoder Reconstruction Error for Anomaly Detection
Encoder mapping $\mathbf{z} = f_\theta(\mathbf{x}) = \sigma(\mathbf{W}_e \mathbf{x} + \mathbf{b}_e)$, Decoder mapping $\hat{\mathbf{x}} = g_\phi(\mathbf{z}) = \sigma(\mathbf{W}_d \mathbf{z} + \mathbf{b}_d)$.
Loss function:
$$\mathcal{L}_{\text{AE}}(\mathbf{x}, \hat{\mathbf{x}}) = \frac{1}{D} \sum_{j=1}^D (x_j - \hat{x}_j)^2 + \beta \sum_{j=1}^D \text{KL}\left(\rho \parallel \hat{\rho}_j\right)$$
Anomaly decision rule:
$$\text{Decision}(\mathbf{x}) = \begin{cases} \text{ATTACK (Anomaly)}, & \text{if } \|\mathbf{x} - \hat{\mathbf{x}}\|^2 > \tau \\ \text{BENIGN}, & \text{otherwise} \end{cases}$$
Where threshold $\tau = \mu_{\text{train}} + k \cdot \sigma_{\text{train}}$ with $k \in [2.5, 3.5]$.
