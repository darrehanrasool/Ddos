# DDoS-AI Research & Literature Repository

This directory contains the state-of-the-art research literature, academic papers (PDFs), extracted methodologies, mathematical formulations, baseline benchmarks, and open research gap analyses.

## Directory Layout

- `pdf/`: Full-text research papers downloaded directly from peer-reviewed venues and arXiv:
  - `ddos_cicddos2019_evaluation.pdf`: UNB CIC-DDoS2019 benchmark & evaluation
  - `ddos_resnet_smote_2024.pdf`: Deep Residual Networks & Synthetic Oversampling for DDoS (arXiv:2401.03116)
  - `ddosdet_neural_networks_2022.pdf`: DDoSDet Neural Network Architecture (arXiv:2201.09514)
  - `ddos_realtime_ml_pca_2025.pdf`: Real-time ML with PCA Feature Selection (arXiv:2501.14311)
  - `ddos_iot_transformer_2025.pdf`: Transformer-based DDoS Detection in IoT (arXiv:2508.10636)
  - `ddos_ganfs_feature_selection_2025.pdf`: GAN-based Feature Selection (GANFS) (arXiv:2504.18566)
  - `ddos_robust_gan_transformer_2026.pdf`: Adversarial Robustness & Transformers for DDoS (arXiv:2609.18281)
- `metadata/`: Structured JSON catalog (`papers_metadata.json`) containing BibTeX, abstract, author list, DOI, dataset, and architectural tags for programmatic parsing.
- `literature_reviews/`: In-depth taxonomic surveys comparing classical ML, Deep Learning, Graph Neural Networks, and Transformers.
- `methodology_extraction/`: Rigorous extraction of mathematical equations, loss functions, and optimization strategies.
- `baseline_comparisons/`: Bit-by-bit tabular benchmark matrix comparing 20 landmark papers across datasets, splits, accuracy, precision, recall, F1, FPR, and hardware.
- `research_gaps/`: Analysis of unsolved security challenges: zero-day attacks, line-rate throughput, adversarial evasion, and real-world deployment.
