# Classical ML Models Directory

In the multi-dataset defense architecture, specialized classical models (HistGradientBoosting / Random Forest)
are organized per network domain in:
  `models/dataset_specialized/<dataset_id>/classical_model.pkl`

Active Domain Models:
- `models/dataset_specialized/cic_ids2017/classical_model.pkl` (Enterprise Cloud)
- `models/dataset_specialized/sdn_ddos/classical_model.pkl` (SDN OpenFlow)
- `models/dataset_specialized/nsl_kdd/classical_model.pkl` (Protocol Infrastructure)
- `models/dataset_specialized/bot_iot/classical_model.pkl` (Smart Home IoT)
- `models/dataset_specialized/ton_iot/classical_model.pkl` (Industrial Telemetry)
- `models/dataset_specialized/cic_ddos2019/classical_model.pkl` (Volumetric Reflection)
